# IGBT Test Bench

Interactive 3D model of an automatic test bench that checks an IGBT before it is installed on a locomotive. Built for the NU–Wabtec Hackathon 2026.

Open the live page: https://khanuxg1.github.io/igbt-test-bench/

Rotate and zoom the bench, click any part to see what it does, pick a healthy or faulty IGBT and press **Run test** to watch the six checks run.
